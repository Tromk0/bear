# 库页湖 · 棕熊

一个无压力的网页小游戏。库页湖的棕熊蹲在河里，鲑鱼季到了，鱼从它面前游过。
你偶尔点一下，它偶尔抓到，偶尔抓不到。

没有分数压力，没有倒计时，没有失败。打开就有事做，关掉就不想它。
limk:https://tromk0.github.io/bear/
## 玩法

- 点击屏幕任意位置（UI 按钮除外），棕熊会扑向河里浮着的鱼
- 鱼会自己潜水，潜水时不可抓，水面会冒泡泡提示
- 三种鲑鱼，分值不同：
  - 红鲑 +10（最常见）
  - 银鲑 +20
  - 王鲑 +50（最稀有）
- 咬空不扣分，只是溅起水花
- 棕熊吃完鱼会留在原地，不回岸边


## 界面

- PC 端：横屏，雪山 + 针叶林 + 像素河，无 UI
- 移动端：竖屏，背景 35% + 游戏区 50% + UI 15%
- 三个按钮：鲑鱼季、库页湖、堪察加，点开是纯文字介绍
- 右上角：当前分数 + 最高分（存在浏览器 localStorage）

## 技术

- 纯 HTML + Canvas + JavaScript，单文件
- 双击 `.html` 即可在浏览器运行，不需要服务器
- 移动端和 PC 端自适应，靠屏幕宽高比判断布局
- 像素素材：棕熊、三种鲑鱼、雪山背景、河流贴图
